# GLCalculator

A basic calculator app made using HTML CSS and JavaScript through which you can perform arithmetic calculations with ease and along with it yours history always stays stored and persistent across page reloads so that you can manage your all calculations did in the past

## Features
- Basic arithmetic calculations
- History storage
- History persistent across page reloads
- ON/OFF buttons
- Clear history buttons
- Dedicated sidebar to manage all your history
- Friendly UI

## Setup

No setup is required for running the project as this is made through pure HTML, CSS and JS just go to the [link](https://glcalculator.netlify.app/) here and start using it
